# CET-6 写作 · 翻译备考台

面向大学英语六级（CET-6）的写作与翻译备考工具。粘贴或上传文本后自动批改打分、指出问题、给出修改建议，并诊断薄弱点、推送针对性训练题。

**在线使用**：https://bween-z.github.io/cet6-coach/

纯静态网页，无需安装，无后端依赖，不收集任何数据。手机上打开后建议「添加到主屏幕」，会以独立 App 形态运行。

---

## 功能

| 模块 | 说明 |
|---|---|
| 写作批改 | 按 8 个维度加权评分（内容切题 20%、结构 15%、连贯 15%、语法 15%、词汇 10%、句式 10%、自然度 10%、模板痕迹 5%），给出问题清单与修改建议 |
| 翻译批改 | 按信息完整 40%、语法 25%、自然度 20%、句法语序 15% 评分，附**漏译自查清单**（把中文拆成信息单元逐条对照） |
| 薄弱点诊断 | 按历史记录中各维度均分排序，找出最弱的三项，并推荐对应的原创训练题 |
| 历史记录 | 分数趋势、逐条回看、导出/导入 JSON |
| 数据同步 | 支持 GitHub Gist 或自建后端，跨设备共用同一份数据 |

评分为**本地规则引擎**，离线可用，不联网、不上传。翻译的语义层面（漏译、选词是否贴切）规则引擎判断不了，因此翻译分标注为「形式层得分」，语义部分由漏译自查清单人工核对。如需 AI 深度批改，可在设置里填入任意 OpenAI 兼容接口的地址与密钥（仅存本机）。

题库为**原创 CET-style 仿真训练**，不复制历年真题。

## 历史数据怎么保存

网页没有后端，数据只能存在「某个地方」，三种方案按可靠性排序：

### 1. 云同步（最可靠，换手机也不丢）

- **GitHub Gist**：设置 → 云同步 → 填入 GitHub token（只需 gist 读写权限）。数据存在你自己的私密 Gist。
- **自建后端**：设置 → 通用云同步 → 填入后端地址 + 同步码。后端用 `cloudflare-worker.js` 部署到 Cloudflare Workers（免费，约 5 分钟），不需要 GitHub 账号。

两台设备填相同的凭据即可共用数据。合并规则：同一条记录取时间较新的，删除操作通过墓碑同步（不会在另一台设备上复活）。

### 2. 本机双层存储（默认）

数据同时写进 `localStorage` 和 `IndexedDB`。部分手机浏览器会清掉前者但保留后者，下次打开会自动从备份找回，并提示找回条数。

### 3. 导出 JSON（兜底）

设置 → 数据管理 → 导出全部数据。换设备或清理浏览器前先导出，需要时导入即可。

> **注意**：微信、QQ 等 App 的内置浏览器在关闭后会清除数据，无痕模式同样会丢。请用 Safari / Chrome 打开并「添加到主屏幕」。

## 自己部署

```bash
node build.js          # 生成 CET6-Coach.html（单文件）、dist/、site/
```

- `CET6-Coach.html`：单文件版，双击即可打开，可整份发给别人
- `site/`：多文件版，适合推到 GitHub Pages 等静态托管
- `cloudflare-worker.js`：可选的同步后端

部署到 GitHub Pages：

```bash
GITHUB_TOKEN=你的token node deploy-gh.js
```

## 目录结构

```
src/
  index.html      页面结构
  styles.css      样式（简约配色，移动端优先）
  engine.js       评分引擎（写作/翻译 rubric、薄弱点诊断）
  questions.js    原创题库（12 写作题 + 12 翻译段）
  store.js        IndexedDB 双层本地存储
  sync.js         云同步（Gist / 自建后端），含合并与墓碑逻辑
  app.js          页面逻辑
build.js          打包（多文件 → 单文件 + dist/ + site/）
deploy-gh.js      GitHub Pages 自动部署
cloudflare-worker.js  自建同步后端
```
